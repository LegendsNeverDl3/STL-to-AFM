# STL-to-AFM
Temporary git location for research in STL to AcousticForceMap
## Idea
Cell-3D Printing must be done either in outer space or in a viscous substance that can provide a scaffold structure.
The can be solved by levitating the object that will be 3d - Printed.
Using an Acoustic levitator, we can create a scaffold mapping for objects- but this requires a force mapping and a visual understanding of that so that a 3d Object(e.g STL) can be converted to force mapping.
